# AI一体化药械经营合规智能监管平台 Demo

这是一个纯前端、无后端依赖的演示原型，用于展示药械经营企业的合规监管工作台：

- 经营合规总览与风险分布
- 高风险批次与效期预警
- 采购、入库、销售、召回的批次追溯
- 合规任务分派与审计留痕
- AI 辅助解释（仅提示，不自动放行或修改业务状态）

## 运行

直接用浏览器打开 `index.html`，或在仓库根目录运行：

```bash
python -m http.server 8000 --directory demos/medical-device-compliance
```

访问 <http://127.0.0.1:8000>。

## 演示边界

页面使用内置演示数据，不连接真实药监平台、ERP、WMS、HIS 或财务系统。AI 区域只生成解释和待办建议，最终复核、放行、召回和处罚决定仍由授权人员完成。
